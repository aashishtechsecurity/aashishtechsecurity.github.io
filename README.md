## 🎯 About The Project

**AashishTechSecurity** is a professional portfolio and resource hub designed for the cybersecurity community. Beyond serving as a personal showcase of skills, experience, and services, it acts as a comprehensive learning platform. It features an interactive **Cybersecurity Mastery Roadmap** that guides beginners and professionals through the various phases of cybersecurity, alongside a curated **Resources Hub** packed with tools, books, and courses.

## ✨ Key Features

- **Dynamic Interactive Roadmap**: A fully animated, step-by-step roadmap taking learners from Foundation to Advanced Cybersecurity concepts.
- **Resource Hub**: A categorized and searchable repository of cybersecurity resources, from beginner tutorials to advanced digital forensics tools.
- **Modern UI/UX**: Built with Framer Motion for buttery-smooth animations and page transitions.
- **Fully Responsive**: Carefully designed to look exceptional on all devices, from mobile phones to ultra-wide monitors.
- **Dark/Light Mode**: Seamlessly integrated theme toggling to suit user preferences.
- **Performance Optimized**: Built on Vite for lightning-fast HMR and optimized production builds.

## 💻 Technology Stack

- **Frontend Framework**: [React 19](https://react.dev/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS v4](https://tailwindcss.com/)
- **Animations**: [Framer Motion](https://www.framer.com/motion/)
- **Routing**: [React Router](https://reactrouter.com/)
- **Icons**: [Lucide React](https://lucide.dev/)
- **Language**: [TypeScript](https://www.typescriptlang.org/)

## 🚀 Getting Started

Follow these instructions to get a copy of the project up and running on your local machine for development and testing purposes.

### Prerequisites

Ensure you have Node.js installed on your system.
* Node.js (v18 or higher recommended)
* npm (comes with Node.js)

### Installation

1. Clone the repository:
   ```bash
   git clone https://github.com/aashishsec/AashishTechSecurity.git
   ```
2. Navigate to the project directory:
   ```bash
   cd AashishTechSecurity
   ```
3. Install the dependencies:
   ```bash
   npm install
   ```
4. Start the development server:
   ```bash
   npm run dev
   ```
5. Open your browser and visit `http://localhost:5173/` to view the application.
